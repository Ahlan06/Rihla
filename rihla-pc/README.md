# Rihla — La halte
Importer project.godot dans Godot 4.4.1 et lancer le projet avec F6 sur Desert.tscn ou F5.
Les flèches haut/bas permettent d’avancer et reculer, gauche/droite de tourner. Maintenir Maj pour galoper. Rejoindre le fanion indigo entre les deux tentes, puis explorer librement.

Cheval animé de Quaternius, Ultimate Animated Animal Pack, CC0. https://quaternius.com/packs/ultimateanimatedanimals.html
Modèle glTF distribué par https://github.com/trebeljahr/quaternius-showcase/tree/main/public/glb/animals_pack
